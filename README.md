# Prime-Produce-Sales-Analysis-Dashboard
Interactive sales analysis dashboard built using Excel to analyze revenue, profitability, product performance, customer trends, and regional sales.

**Dashboard Features:**
1. Time Analysis: Monthly, quarterly, yearly, and weekday profit trends.
2. Sales KPIs: Total quantity, revenue, cost of goods sold, profit, profit margin, and transactions.
3. Product Analysis: Product profitability, product availability, sales status, and pricing distribution.
4. Customer Analysis: Top-performing customers, customer demographics, and age-group contribution.
5. Geographical Analysis: Country-wise sales and profit contribution.
6. Interactive Filters: Dynamic filtering by year, month, country, and other dimensions.

**Tools Used:**
1. Microsoft Excel
2. Pivot Tables
3. Data Visualization
4. Interactive Dashboard Design
